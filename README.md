# resumo-lab-tipos
Contém um resumo dos tipos de nuvem

Resumo: Tipos de Nuvem
1. IaaS (Infraestrutura como Serviço)
O que é? Fornece a estrutura básica de computação (servidores, armazenamento, rede).

Controle: O cliente gerencia sistemas operacionais, aplicações e configurações.

Exemplo: Alugar um servidor virtual e configurá-lo como quiser.

2. SaaS (Software como Serviço)
O que é? Software pronto para usar, acessado online sem instalação.

Controle: O provedor cuida de tudo; o usuário só usa o programa.

Exemplo: E-mail (Gmail), ferramentas de trabalho (Google Docs).

3. PaaS (Plataforma como Serviço)
O que é? Ambiente para desenvolver e gerenciar aplicações sem se preocupar com infraestrutura.

Controle: Foco no desenvolvimento; o provedor gerencia servidores e redes.

Exemplo: Plataformas para criar apps (Microsoft Azure, Heroku).

Comparação Rápida
IaaS: "Alugo um computador vazio e instalo o que precisar."

PaaS: "Umo um laboratório pronto para criar programas."

SaaS: "Uso um programa pronto, sem me preocupar com nada."
